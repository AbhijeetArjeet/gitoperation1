Git & GitHub Pro

Click any command to copy it to your terminal

🚀 Setup & Starting

git config --global user.name "Name"

Sets the author name attached to your commits.

git config --global user.email "Email"

Sets the author email attached to your commits.

git init

Initializes a new, empty Git repository locally.

git clone <url>

Downloads an existing project to your computer.

⚡ The Daily Workflow

git status

Shows modified files and what is ready to commit.

git add .

Stages all modified and new files for the next commit.

git commit -m "Message"

Saves your staged changes locally with a message.

git push origin main

Uploads your local commits to the remote repository.

git pull origin main

Downloads new commits and merges them locally.

🌿 Branching & Merging

git branch

Lists all local branches. Active branch has a (*).

git checkout -b <branch>

Creates a new branch and instantly switches to it.

git checkout <branch>

Switches to an existing branch.

git merge <branch>

Combines code from the specified branch into yours.

⏪ History & Undoing

git log --oneline

Shows a compact, readable history of past commits.

git restore <file>

Discards uncommitted changes in a specific file.

git revert <hash>

Creates a new commit that safely undoes a past commit.

git reset --hard HEAD~1

DANGER: Permanently deletes your most recent commit.

🔥 Advanced Git

git stash

Temporarily shelves uncommitted changes.

git stash pop

Brings back the changes you previously stashed.

git rebase main

Rewrites your branch history to start from main's tip.

git bisect

Uses binary search to find exactly which commit broke code.

🐙 GitHub CLI (gh)

gh auth login

Authenticates your GitHub account from the terminal.

gh repo create

Creates a brand new GitHub repository remotely.

gh pr create

Opens a new Pull Request for your current branch.

gh issue list

Lists all open issues in the current repository.
