Git & GitHub Cheat Sheet

Your ultimate reference for version control

1. Setup & Starting

git config --global user.name "Name"

Sets the author name attached to your commits.

git config --global user.email "Email"

Sets the author email attached to your commits.

git init

Initializes a new, empty Git repository locally.

git clone <url>

Downloads an existing repository from GitHub to your computer.

2. The Daily Workflow

git status

Shows modified files and what is ready to be committed.

git add .

Stages all modified and new files for the next commit.

git commit -m "Message"

Saves your staged changes locally with a descriptive message.

git push origin main

Uploads your local commits to the remote repository (GitHub).

git pull origin main

Downloads new commits from GitHub and merges them locally.

3. Branching & Merging

git branch

Lists all local branches. The current branch has an asterisk (*).

git checkout -b <branch-name>

Creates a new branch and immediately switches to it.

git checkout <branch-name>

Switches to an existing branch.

git merge <branch-name>

Combines code from the specified branch into your current working branch.

4. History & Undoing

git log --oneline

Shows a compact history of all previous commits.

git restore <file>

Discards uncommitted changes in a specific file.

git revert <commit-hash>

Creates a new commit that undoes the changes of a past commit safely.

git reset --hard HEAD~1

DANGER: Permanently deletes your most recent unpushed commit.

5. Advanced Git

git stash

Temporarily shelves uncommitted changes so you can switch branches.

git stash pop

Brings back the changes you previously stashed.

git rebase main

Rewrites your branch's history to start from the tip of the main branch.

git bisect

Uses binary search to find the exact commit that introduced a bug.

6. GitHub CLI (gh)

gh auth login

Logs you into GitHub from your terminal.

gh repo create

Creates a brand new GitHub repository from your terminal.

gh pr create

Opens a new Pull Request on GitHub for your current branch.

gh issue list

Lists all open issues in the current repository.
